## Tools List
- Red Robertson screwdriver
- Needle-nose pliers
- Wire stripper pliers
- Allen key set
- 7/16in. box/open-end wrench
- 1/8in. terminal driver
- Flush cut pliers
- Phillips screwdriver
- Power drill (0.25in. and 0.125in. bits)
- Multi-tool/router (semi-precise cutting)
- Measuring tool (scale or caliper)
- Marking tool (Sharpie)

## Key Components
- Trailer: dump-style trailer chassis + stainless steel mounting plates
- Firing/reload system: 18V DC motors, flywheels, MG90 continuous servo, brass rod linkage
- Barrel: PVC pipe + 3-way connector
- Electrical: breadboard, Arduino Uno, XY160D power supply module, jumper wires

Full step-by-step build instructions with figure references are in `fabrication-guide.pdf` in this folder.
